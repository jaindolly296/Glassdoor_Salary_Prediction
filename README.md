# 💼 AI-Powered Glassdoor Salary Prediction & Career Insights System

An end-to-end Machine Learning project that predicts employee salaries using historical Glassdoor job listings and provides AI-powered career insights using the Groq LLM.

---

# Project Overview

This project combines Data Analysis, Machine Learning, Data Visualization, and Generative AI into a single web application.

Users can:

✔ Predict expected salary

✔ Compare market salary trends

✔ Get AI-generated career advice

✔ Understand required skills

✔ Explore salary insights across industries

---

# Business Objective

The objective of this project is to build an intelligent salary prediction system that helps:

- Job seekers estimate salaries.
- Recruiters benchmark compensation.
- HR teams improve hiring strategies.
- Organizations understand salary trends.

---

# Problem Statement

Salary estimation varies based on several factors including:

- Job Title
- Industry
- Company Rating
- Company Size
- Location
- Business Sector

This project aims to predict salaries using Machine Learning while providing AI-generated career recommendations.
